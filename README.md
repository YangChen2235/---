# 班级抽卡-重置版

> 个人的游戏练习作品。
> 本来只是想跑起来，结果越做越大，最后长成了一个发展得有点奇怪的东西。
> 代码写得奇怪，**不建议参考**，看得开心就好。

一个用 **Godot 4.7** 做的单机小游戏：抽卡 + 打牌，缝了一堆想到就做的元素进去。

一句话概括：**把班里的同学抽成卡，然后带他们去打牌。**

> 先说清楚：项目里现在**所有美术素材都是网上下载的临时占位图**（原神官方素材的第三方镜像），
> 只用于开发期看效果，**不能用于发布**。详见 [`图片/临时美术说明.md`](图片/临时美术说明.md)。

## 一、玩法介绍

这是一个缝合了多种元素的世界，属于是想到啥做啥。
但别被吓到，它的主要玩法就两件事：**抽卡**、**打牌**。

### 一，抽卡

抽卡我参考了《原神》等二次元游戏的抽卡画面，所以你可以看到我的抽卡界面充斥着大量外来的二次元素材。

- **点击抽取一次**，可以获得一个角色的提升，以及一颗**蓝源碎片**。
- **点击抽取十次**，可以获得十个角色的提升，以及一颗**红源碎片**。

抽到角色 = 这个角色直接变强（生命 +2、幸运 +1），所以抽卡在这游戏里是**正经的养成入口**，不是单纯好看。

抽卡界面顶上一排按钮切页：

| 页 | 抽什么 | 花什么 |
| --- | --- | --- |
| **祈愿-常驻** | 当前班级的全部同学 | 免费 |
| **祈愿-限定** | 从班里随机挑 10 位当"本期限定" | 免费 |
| **定轨** | 你自己指定的那一位 | **蓝源碎片**（单抽 3） |

**定轨**是后来加的：从全部同学里挑一位当目标，"歪了"就攒一格幸运值，攒满 10 格下一次必中；
抽中目标 → 幸运值清零。右边有个充能圆环，数字就是 `幸运值 / 10`。

> 抽卡动画是一张一张翻的：天降 → 定身 → 光带扫过 → 开图 → 报名字，一张约 0.75 秒，
> 十连错开播放，整批约 1.8 秒播完。同一张脸抽到第二次，卡面上会显示"第 N 次抽到"。

### 二，打牌

打牌叫**骰子对决**，两边各一个角色，轮流出牌对砍。

**核心规则（很朴素，就四条）：**

1. **骰子就是行动点** —— 每个大回合掷两颗骰子，点数之和 = 你这回合的行动点；
   两颗骰子点数一样，额外再送一份。上限默认 10（想吃满 12 点得靠装备 / 场地 / 提神咖啡抬上限）。
2. **一个回合出一张牌** —— 出牌要花行动点，出不起的牌会**变灰**，点它会红闪并告诉你为什么出不起。
3. **三种去向** —— 同样的手牌，放哪儿决定它什么时候生效：
   - **行动栏**：打出去立刻结算，回合结束进弃牌堆。
   - **胃囊**：先存着，**下个大回合开始**才消化成本回合的加成。
   - **装备**：挂上去常驻，一直算。
4. **附着一套** —— 打出一张带类别（元素 / 物质 / 能量 / 岩 / 细胞…）的牌，会给对手挂上这个类别；
   下一张打**另一个**能跟它反应的类别，就触发反应：**伤害 ×倍率 + 附带效果**，
   反应完附着变成新的类别 —— 所以一回合能一直连下去。

**赢法**：先堆条件（胃囊 + 装备攒张数），再放高倍率牌收割。
这是后面所有卡组第 6 关都在教的同一个骨架：**先堆数量、后放倍数**。

## 二、打牌这边有什么

### 十套卡组，每套 100 张以上

每套卡组 = 本局双方牌堆用的一整副牌。开打前选一套。

| 卡组 | 核心隐喻 | 张数 |
| --- | --- | --- |
| 玉溪一中（最初的） | 元素相遇 → 反应 | 106 |
| 化学卡组 | 物质相遇 → 反应 | 196 |
| 物理卡组 | 九种能量互相转化 | 162 |
| 地理卡组 | 地质循环（岩浆→沉积→变质→重熔） | 172 |
| 生物卡组 | 细胞结构 → 生命活动 | 131 |
| 语文卡组 | 字词句段篇 + 修辞 + 文体 | 140 |
| 数学卡组 | 数学对象联立 → 定理 / 解法 | 131 |
| 英语卡组 | 词性 + 语法 → 句式 / 语篇 | 123 |
| 政治卡组 | 四大模块概念交叉 → 原理 | 155 |
| 历史卡组 | 7 时期 × 4 领域 的二维网格 | 123 |

外加四套**附加卡组（DLC）**：骰子 / 存储 / 食堂 / 黑市 —— 和主卡组共存、可叠加，买过才解锁。

举个化学卡组的例子，反应表长这样：

| 打出 | 对手身上 | 反应 | 伤害 | 附带 |
| --- | --- | --- | --- | --- |
| 碱金属 | 水 | 碱金属与水 | **×2.3**（全表最高） | 自己暴击 +10%、削对手 1 行动 |
| 卤素 | 金属 | 卤素与金属 | ×1.9 | 附着变成「盐」 |
| 酸 | 碱 | 中和反应 | ×2.2 | 自己回血 3 |
| 氧气 | 非金属 | 燃烧 | ×1.8 | 附着变成「酸性氧化物」 |
| 水 | 过氧化物 | 分解反应 | ×1.0 | 自己回血 5 + 抽 1 张（不靠伤害） |

每套卡组的完整反应表在 `规则/` 目录下的对应规则文件里（纯函数，没有状态）。

### 图鉴 → 玩法提示 = 现算的上手教程

游戏里点 **图鉴 → 某套卡组 → 玩法提示**，能看到这套牌的上手教程：
在玩什么 / 三种牌怎么用 / 四类工具牌怎么用 / 三套连招 / 本套最强的 8 条反应 / 类别速查。

这份教程是**读规则表现算出来的**——改倍率、加类别之后提示自动跟着变，不用维护第二份文案。

## 三、单人肉鸽：主题战役（元素周期表）

主界面 →「主题战役」，一个缝合了**深渊 + 肉鸽 + 搜打撤**的模式。

```
层（= 元素周期表的一个周期）
 └ 地区（= 一个元素，比如"氢"）
      └ 房间 3~5 个（对决 / 小卖铺 / 恢复 / 剧情）
```

| 层 | 周期 | 战利品 | 可拿到几级卡 | 地区数 |
| --- | --- | --- | --- | --- |
| 1 | 第一周期 | 1★ | ≤1 级 | 2 |
| 2 | 第二周期 | 2★ | ≤2 级 | 8 |
| 3 | 第三周期 | 2★ | ≤3 级 | 8 |
| 4 | 第四周期 | 3★ | ≤4 级 | 8 |
| 5 | 第五周期 | 3★ | ≤5 级 | 8 |
| 6 | 第六周期 | 4★ | ≤6 级 | 8 |

**术语全都翻成了化学**（对标模拟宇宙）：

| 模拟宇宙 | 这里 |
| --- | --- |
| 命途 | 化学分支（9 个） |
| 祝福 | 试剂（54 条） |
| 命途回响 | 共振 |
| 奇物 | 催化剂（10 个） |
| 方程 | 化学方程式（6 条） |
| 倒计时 | 半衰期 |

**搜打撤是这个模式的灵魂**：

```
打赢对决 → 战利品进"本局暂存" → 撤离 → 才进背包、化学键才到账
失败 / 主动放弃 → 本局战利品和化学键全部清空
```

另外还有：10 项技能提升（天赋树：爆率 / 生命 / 攻击 / 防御 / 卡牌限制 / 背包大小 /
利润 / 化学键获取 / 试剂候选 / 半衰期）、黑市（买价永远高于卖价，倒卖赚不到钱）、
战役背包（上场 ≤20 张 + 按等级分档限制）、分歧存档点（走错路可以整局倒回去重选）。
每个地区是**固定阶段模板**：三场战斗，每场之间选「打」还是「跑路拿收益」。

## 四、其他塞进去的东西

- **主线剧情 / 序幕**：7 场对决，对手兼讲解员是玉薛宝。
  结构是「每章 6 关 + 1 个章节首领，**一关只教一个知识点**」。
  打不过不算失败（你血空了对手会给你回一口继续教），
  过关条件**不看输赢**，只看那个知识点有没有做到。
- **一代对决（1V1 淘汰赛）**：从老项目还原的原始玩法，规则更简单，全 AI。
- **单词对决**：对标天学网的英语对决，双方抢答同一道题（键盘 `A S D F` / `J K L ;`）。
  词库 7 册（必修一~三、选必一~三、高中3500，合计约 4700 词）。
- **迷你游戏大厅**：单词对决已上线，记忆翻牌 / 速算对决 / 元素接龙 / 猜拳对决 / 找不同施工中。
- **首领战**：三只首领（玉薛宝 / log根 / JK-KING），各 4 张专属牌、独立机制、四档难度、弱点破防。
- **排行榜、小卖铺、隐藏卡、不死图腾、成就提示栏、班级背包、段位系统**……

**段位**用的是修仙那套：凡人期 → 炼体期 → 开脉期 → 筑基期 → 金丹期 → 元婴期 → 化神期 →
渡劫期 → 大乘期 → 真神期 → 无限期 → 虚无期 → 归终期（13 段，每段再分初期~末期）。
分数是按战力分数算的，卡牌等级门槛跟段位用同一套数——所以"这张牌什么段位能用"是可以查的。

## 五、怎么跑起来

**需要**：Godot **4.7**（GL Compatibility 渲染后端，纯 2D，不用独立显卡）

```powershell
# 用编辑器打开
godot --path .

# 或者直接跑主场景
godot --path . res://场景/主界面.tscn
```

分辨率 1920×1080（`canvas_items` 拉伸），另外做了触摸屏兼容：全局屏幕 Esc 按钮 +
所有滚动容器支持按住拖动。

**存档**在 `user://班级抽卡存档.json`（启动时自动读档），
也可以从设置里**导出 / 导入**存档（导出到 `user://导出存档/`，文件名带毫秒，字典序就是时间序）。

### 第一次进游戏

1. 先选"新手 / 老玩家"。
2. 走序幕：第 5 关讲到抽卡之后，「开始抽卡」才解锁；打完序幕首领，
   「开始对决 / 迷你游戏 / 主题战役」一起解锁。
3. 想直接看东西的话：**设置界面里连着按 `YangChen2235`** → 输入密码 `20091028` 进开发者模式，
   之后**按 T** 呼出指令台（打「帮助」看全表：加源碎片、全员满级、解锁隐藏卡、给卡、一击必杀…）。

### 导出

`export_presets.cfg` 里已经有 Windows Desktop 的预设，`_验/` 和 `数据/_scratch/` 会被排除。

### 自测

项目里有 12 个 `--headless` 自测场景、合计约 830 条断言，全部跑一遍失败 0 项：


## 六、代码长什么样（想参考的话……还是别参考了）

### 目录

| 目录 | 放什么 |
| --- | --- |
| `类/` | 实体类。一个对象"是什么、能做什么" |
| `核心/` | 自动加载：状态、数据表、算法、界面之间的中转 |
| `规则/` | 纯规则 / 纯函数：元素反应、化学反应、能量转化、地质作用… |
| `系统/` | 与玩法无关的通用能力：动画、音频、存档、图源、提示栏 |
| `界面/` | 所有界面脚本 `.gd` + 界面组件 `.tscn`，按玩法分子目录 |
| `场景/` | 可以被切换进去的整页场景 |
| `数据/` | JSON 数据表（含 `数据/词库/` 的 7 套英语词库） |
| `图片/` `音乐/` `字体/` `主题/` | 素材 |
| `_验/` | `--headless` 自测场景，不属于游戏内容，打包时排除 |

### 分层约定

```
类层      类/*.gd            一个对象是什么、能做什么；只发自己的信号
管理层    核心/*管理.gd       数据表 + 算法 + 结算；把类层信号转成全局信号
总线层    核心/*总线.gd       界面之间的请求 / 通知中转，不存业务数据
全局层    核心/对局状态.gd     纯状态 + 全局信号登记
规则层    规则/*.gd           无状态纯函数
系统层    系统/*.gd           通用能力，不认识玩法
界面层    界面/*.gd           只负责显示和转发输入
```

有几条规矩是自己定的，踩过坑之后就不敢破了：

1. **类层不认识任何自动加载。** 想发全局信号就自己 emit，由管理层转发。
2. **界面只 connect 总线 / 状态类信号**，不直接去读别的管理对象的内部数组。
3. **数据放 JSON，逻辑放 GDScript。**
4. **常驻 UI 节点全部写在 `.tscn` 里**，不用代码 `new` 出来——只有这样改界面才能直接进编辑器拖。
5. **谁的数据谁导出**：存档只读写文件，碎片归 `对局状态`、名册归 `学生管理`、设置归 `设置总线`。

### 近千张卡是脚本生成的

十套卡组 × 100+ 张，手写既慢又容易写错，所以卡表是生成出来的：

```
数据/_scratch/卡名库.py          # 卡名池（人写，按"类别 → 名字列表"）
数据/_scratch/生成卡组扩充.py    # 生成逻辑 → 核心/卡组扩充数据.gd（别手改）
数据/_scratch/生成卡面_线稿.py   # 批量出卡图 → 图片/卡牌插画/
```
